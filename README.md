# Šablona webu Dětský svět Skalička

WordPress šablona pro svetskalicka.cz. Jen kód, bez fotek a osobních údajů.

- `skalicka/` – šablona (to, co se instaluje do WordPressu)
- `zemekoule-zdroj/` – zdroj animované zeměkoule u počítadla kilometrů (sestavuje se do `skalicka/assets/js/zemekoule.js`)

Nová verze = GitHub release s přiloženým souborem `skalicka-sablona.zip`. Web si ho stáhne v Nastavení → Skalička → Aktualizace šablony.
